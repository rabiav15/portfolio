# 👨‍💻 Kişisel Portföy Web Sitesi

Modern, tamamen responsive ve Bootstrap 5 tabanlı kişisel portföy web sitemin kaynak kodlarıdır. 
Bu proje; eğitim geçmişimi, donanım/yazılım deneyimlerimi ve geliştirdiğim akademik/bireysel projeleri estetik bir biçimde sergilemek amacıyla tek sayfa (Single Page) mimarisinde tasarlanmıştır.

## 🚀 Canlı Demo
Projeyi canlı olarak incelemek için tıklayın: [Portföy Web Sitem](https://rabiav15.github.io/portfolio)

## ✨ Öne Çıkan Özellikler
* **Responsive Tasarım:** Tüm cihazlarda (mobil, tablet, masaüstü) kusursuz çalışan Bootstrap grid sistemi.
* **Etkileşimli UI:** Özel hover animasyonları, renk uyumlu proje kartları ve detayları gösteren Modal (Pop-up) pencereler.
* **Proje Vitrini:** Akıllı Tarım (IoT & Derin Öğrenme), NoSQL vs SQL Kıyaslamaları, C/POSIX Sistem Programlama ve Ağ Konfigürasyonu gibi mühendislik projelerinin detaylı sunumu.
* **Dinamik İletişim Formu:** Web3Forms API entegrasyonu ile arka planda çalışan, spam korumalı (honeypot) aktif iletişim formu.

## 🛠️ Kullanılan Teknolojiler
* **Frontend:** HTML5, CSS3, Bootstrap 5.3
* **İkonlar ve Görseller:** FontAwesome 6, Unsplash API
* **Backend / Form Yönetimi:** Web3Forms API (Sunucusuz mesajlaşma)
* **Deployment (Yayınlama):** GitHub Pages

## ⚙️ Kurulum ve Geliştirme
Bu proje tamamen statik dosyalardan oluştuğu için herhangi bir paket yöneticisine (npm, pip vb.) veya karmaşık bir yerel sunucu kurulumuna ihtiyaç duymaz.
