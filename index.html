Smart Agriculture Prototype
Main Goals

To develop an end-to-end system for detecting plant diseases and monitoring environmental factors to improve agricultural productivity.

Concept and Technologies

Environment data (DHT11 etc.) and plant images captured with ESP32-CAM module were transmitted to a server. Images were classified into 38 different plant diseases using MobileNetV2 (Transfer Learning). Data was processed with Apache Spark and visualized on a Flutter-based mobile assistant.

DB Performance Benchmarking
Main Goals

To analyze the performance limits and response times of relational (MySQL) and NoSQL (MongoDB) database management systems under different query types.

Concept and Technologies

Test scripts written in Python were sent to MongoDB and MySQL servers running on Docker containers. CRUD (Create, Read, Update, Delete) operations and complex Join/Aggregation operations were tested on large datasets (e.g., flight data), with response times measured in milliseconds.
